# Second Look v0.2.0 — a first result you can inspect

This preview makes the project easier to try and evaluate: a bundled synthetic history, three complete generated deliverables, a strong-prompt comparison, clearer bilingual installation, explicit upgrade backups and ready-to-edit launch materials.

- Start with the demo before granting personal-history access.
- Inspect a constrained research plan, a tested offline-search draft and a four-part application.
- Read both independent exercise outputs. The ordinary strong prompt also performed well; no superiority is established.
- Download `skill.zip` for compatible standard skill surfaces, `openai-plugin.zip` for supported plugin surfaces, or `launch-kit.zip` for copy and artwork. The plugin package is not a marketplace listing.
- Upgrades made with the Python installer preserve the prior install outside the active skills directory. Private review data stays separate.

Verification includes 44 runtime tests, structural checks, archive checks and independently rerun demo code. The runtime suite and build passed all six Ubuntu/macOS/Windows × Python 3.9/3.12 CI combinations; the POSIX permission check is skipped on Windows. See the compatibility matrix for exact environments. The 24-case model evaluation, native account-history workflows and 10-person/two-week pilot remain outstanding.
