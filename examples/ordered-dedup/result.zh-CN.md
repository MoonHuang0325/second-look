# 保持首次出现顺序的去重函数

```python
def unique_ids(ids):
    return list(dict.fromkeys(ids))
```

**有依据的改进。**对字符串 ID 返回一个新列表，保留首次出现顺序，并且不修改输入。旧方案 `sorted(set(ids))` 会主动排序，把 `["b", "a", "b"]` 变成 `["a", "b"]`，违反用户要求的 `["b", "a"]`。

选择它的依据是：用户后续明确报告了仍存在的错误，也明确说明继续使用 Python 3.9。来源：[合成对话](history.md)。Python 3.9 的字典保留插入顺序。仓库中的演示回归测试实际执行新旧函数，检查空输入、单项、重复项、混合顺序、返回新列表以及输入不变。

没有修改任何线上项目。覆盖范围为一段合成对话与一个函数。这是包含实际回归检查的人工演示，不是独立模型评测或用户效果评测。
