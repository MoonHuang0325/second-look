# 60 秒演示录制脚本

这是一份待录制脚本，不是已经拍好的视频。使用仓库自带的合成历史，不打开个人聊天列表。全程角落标记“合成演示 / Synthetic demo”。录到实际等待可以剪辑，但显示“已剪去等待”，不暗示固定完成速度。

| 时间 | 画面 | 旁白建议 |
| --- | --- | --- |
| 0–6 秒 | 简洁标题，再展示合成历史的一条旧结论 | “以前和 AI 聊过、最后卡住的事，换个时刻再看，可能有新的答案。” |
| 6–15 秒 | 新任务中实际输入 demo 调用；显示只读合成材料 | “Second Look 会重新找目标、看后续修正，再交付可以用的新版成果。先用合成材料试，不碰个人历史。” |
| 15–29 秒 | 实际生成的研究方案：800 元、12 人时；对照原文约束 | “这里不再等代理预算，而是按已有资源形成访谈试点。数字有出处，工时可以核对。” |
| 29–41 秒 | 实际运行离线搜索测试，显示真实结果 | “这里交付的是代码，并检查查询和原文件是否保持不变。小样本通过，不等于大规模性能已经验证。” |
| 41–51 秒 | 展示完整四段申请正文及字数检查 | “也可以是一份回到真实用途的申请正文。未确认的预算和场地信息仍然保留待办。” |
| 51–60 秒 | 仓库首页与演示入口 | “项目重启、约束变化，都值得再看一次。开源预览版，欢迎试用并告诉我哪里没做好。” |

如果实跑结果与公开示例不同，展示自己的实际结果。不能用提前生成的答案伪装成现场输出；若展示已保存结果，标注“已保存的演示结果”。如果只能做静态讲解，直接这样标注。

录前隐藏通知、邮箱、文件路径和账号信息。录完检查每一帧，公开上传由账号所有者完成。封面可用 [社交图片](../../assets/social-preview.png)，图中没有性能或采用率承诺。
