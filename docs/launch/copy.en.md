## Show HN draft

Title: Show HN: Second Look – revisit old AI conversations and deliver revised work

I built Second Look around a recurring frustration: an important conversation stops, new constraints arrive elsewhere, and the old answer never gets reconsidered unless you remember to ask again.

It is an MIT-licensed Agent Skill for revisiting accessible history, restoring the current goal and producing usable revised work. The default is 1–3 results, with evidence and a clear option to keep the original conclusion.

You can try a bundled synthetic history without granting personal-history access. The repository includes generated research, coding and writing outputs, executable checks, and an ordinary strong-prompt comparison. Both approaches did well on that pack; this is an illustrative exercise, not proof of superiority.

Codex and Claude Code installation routes are documented. Native history access varies by host, and ChatGPT/Claude account-specific upload and history workflows are still unverified. There is no developer backend or extra API service; your host model still processes the material it reads.

I'd welcome concrete cases where the review misses the real goal, produces no meaningful improvement, or should have left something closed. Please share a synthetic/minimized reproduction rather than private transcripts.

Try it: https://github.com/MoonHuang0325/second-look
